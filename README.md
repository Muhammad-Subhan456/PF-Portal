# Programming Fundamentals Portal

PUCIT Programming Fundamentals teaching portal (Vite + React + Supabase).

## Quick start

```bash
npm install
# Copy .env.example → .env and fill Supabase keys (see CREDENTIALS_SETUP.md)
npm run dev
```

App: http://localhost:8080

**Full credentials setup (new Supabase + Google OAuth + deploy):** see [CREDENTIALS_SETUP.md](CREDENTIALS_SETUP.md).

**Manual QA / how the portal works:** see [TESTING_WORKFLOW.md](TESTING_WORKFLOW.md).
